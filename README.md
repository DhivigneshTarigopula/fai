## 🚀 Features

- 🔍 **Stock Search** – Search companies using names or ticker symbols.
- 📊 **Company Overview** – Explore important financial metrics.
- 📈 **Historical Charts** – Visualise stock price movements.
- 💱 **Currency Conversion** – View prices in multiple currencies.
- 🤖 **AI Assistant** – Ask questions about companies and financial concepts.
- 🔄 **Auto Refresh** – Refresh stock information every minute.

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- yfinance
- Yahoo Finance
- Groq AI

## 📌 About

StockIt combines stock market data, interactive visualisations and AI-assisted explanations in one dashboard.

## ⚙️ Run Locally

```bash
git clone https://github.com/DhivigneshTarigopula/fai.git
cd fai
pip install -r requirements.txt
streamlit run app.py
```
